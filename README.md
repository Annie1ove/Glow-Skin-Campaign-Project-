# Social Media Campaign Project

## Overview

A simulated social media campaign created to demonstrate
project planning and task management skills.

## Tools Used

- Trello
- Canva
- Google Workspace
- Pinterest

## Project Management Skills Demonstrated

- Task creation
- Task assignment
- Due dates
- Checklists
- Labels
- Workflow organization
- Project tracking
- Milestones
- Dependencies

## Project Workflow

Ideas → Content Creation → Review → Approval → Scheduling → Publishing

## Outcome

Created a structured workflow for managing a social media
campaign from planning through publishing.
